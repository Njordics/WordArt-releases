# WordArt releases

Download builds of **WordArt**, the cozy Android coloring game where you earn paint by solving an endless
word search.

**Install:** open the [latest release](https://github.com/Njordics/WordArt-releases/releases/latest) on your
Android phone (Android 8.0+), download the `.apk` and open it. Android will ask you to allow installs from
your browser the first time.

**Updates:** the app checks this page on its own and offers new versions in-game, so you only need to
install it once.

This repository only holds release builds. Every APK is signed with the same WordArt key; Android refuses
an update signed with anything else.
